
# LearningDesk

桌面学习计划工具，支持每日任务、睡前记录、周期总结、AI 学习建议。

## 功能

- **今日计划**：添加/编辑/删除每日任务，标记完成状态
- **睡前记录**：记录每日学习心得
- **周期总结**：生周/半月/月总结
- **学习建议**：结合历史数据调用 AI 生成学习建议
- **历史回顾**：查看历史任务和记录
- **设置**：配置 OpenAI 兼容接口

## 技术栈

- Python 3
- CustomTkinter (GUI)
- SQLite (数据库)

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 打包

```powershell
.\build_exe.ps1
```
